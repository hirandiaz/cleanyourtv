# Chromecast with Google TV HD (device boreal), Google TV 14 (SDK 34), build UTTC.250917.004
# Debloat plus the custom launcher (launcher/build-and-install.sh, 2026-10-21). The installer disables the
# stock Home (com.google.android.apps.tv.launcherx); Batch 5 disables the setup wizard so the new Home
# sticks, which breaks casting after every reboot (see README).
# Based on examples/google-chromecast-gtv-4k/debloat.txt. Verified 2026-10-21: every entry below
# stays disabled after a reboot (no firmware re-enable list on this build).
#
# Apply:   TV_HOST=<ip> tools/disable.sh examples/my-chromecast-gtv-hd/debloat.txt
# Undo:    TV_HOST=<ip> tools/restore.sh examples/my-chromecast-gtv-hd/debloat.txt com.google.android.apps.tv.launcherx
#
# Kept on purpose: Google Assistant (katniss), Cast receiver (mediashell), remote firmware updates
# (dfuservice), Google TV app (videos), ambient mode (dreamx, backdrop), Play Store / Play Services,
# Gboard, phone remote service.

# Batch 1: telemetry and feedback
com.google.android.feedback
com.android.tv.feedbackconsent
com.google.android.tv.remotecontrol.logging     # remote usage logging

# Batch 2: Privacy Sandbox / federated-learning Mainline modules. Re-enable if the Play Store or
# Assistant misbehave.
com.google.android.federatedcompute
com.google.android.ondevicepersonalization.services
com.google.android.adservices.api               # Privacy Sandbox ad services
com.google.android.ext.adservices.api

# Batch 3: preloaded apps
com.google.android.play.games
com.android.printspooler
com.google.android.marvin.talkback              # re-enable if you need the screen reader

# Batch 4: streaming apps not used (owner's choice). Disabled first, then UNINSTALLED on 2026-10-21
# (pm uninstall) to free ~300 MB. restore.sh prints an "unknown package" error for the three still uninstalled; that is
# harmless. Reinstall them from the Play Store if wanted.
com.wbd.stream                                  # HBO Max
com.movistarplus.androidtv                      # Movistar Plus+
com.orange.es.androidtv                         # Orange TV
# tv.accedo.mitele_xdk                          # Mediaset Infinity: reinstalled from the Play Store, in use

# Batch 5: setup wizard, so the custom launcher stays as Home. Casting from phones then fails with
# "Untrusted device" after every reboot until setupwraith is re-enabled for a minute and disabled

com.google.android.tungsten.setupwraith
